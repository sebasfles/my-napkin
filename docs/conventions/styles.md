# Styles

The app is styled with Tailwind and shadcn/ui, and every color comes from the theme tokens so that light and dark mode are always both covered.

## Rules

- Colors are expressed only through the semantic classes shadcn defines from the tokens (`bg-background`, `text-foreground`, `bg-primary`, `text-primary-foreground`, `text-muted-foreground`, `border-border`, `bg-card`, `bg-destructive`, `ring-ring`, and the rest of the set) or through `var(--token)` in CSS.
- Token values (`--background`, `--foreground`, ...) are declared once, in `app/src/globals.css`, under `:root` and `.dark`. No other file declares a color value.
- No hex, `rgb()`, `hsl()` or `oklch()` literal appears outside `app/src/globals.css`.
- No Tailwind palette class (`text-red-500`, `bg-zinc-900`, `border-gray-200`) and no arbitrary color value (`bg-[#fff]`, `text-[rgb(...)]`) appears anywhere.
- No `dark:` variant is used to change a color; the tokens already switch with the `.dark` class. `dark:` remains valid for non-color properties.
- Theme switching uses `next-themes` with the class strategy; the Excalidraw component receives `theme` derived from the app theme so the canvas follows it.
- Icons and SVGs use `currentColor` and take their color from the surrounding text token.

## Allowed

- `app/src/globals.css`: the token declarations.
- `app/src/components/ui/*`: files generated by the shadcn CLI, kept as generated.
- Test files under `app/tests/`.
