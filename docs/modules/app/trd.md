# app: technical

The editor shell exists: the layout, the embedded editor, the theme and the locale.
Persistence, the API routes and the auth gate do not, and are marked planned below.

## Structure

| Path | What | Status |
|---|---|---|
| `app/src/app/layout.tsx` | Root layout, sets `lang`, mounts the intl and theme providers | now |
| `app/src/app/page.tsx` | Sidebar plus editor, server component | now |
| `app/src/app/globals.css` | Tailwind and the theme tokens (CSS variables, light and dark) | now |
| `app/src/components/` | Editor wrapper, sidebar, theme and locale toggles | now |
| `app/src/components/ui/` | shadcn/ui components, generated by its CLI | now |
| `app/src/i18n/` | `next-intl` request config and locale resolution | now |
| `app/src/lib/` | Pure helpers: theme resolution, editor language mapping, hydration gate | now |
| `app/src/messages/{es,en}.json` | `next-intl` messages, one key set for both locales | now |
| `app/tests/unit/` | Vitest, pure logic only | now |
| `app/tests/e2e/` | Playwright, one spec per flow | now |
| `app/src/app/login/page.tsx` | Password form | planned |
| `app/src/app/api/diagrams/route.ts` | GET list, POST create | planned |
| `app/src/app/api/diagrams/[id]/route.ts` | PATCH rename, DELETE | planned |
| `app/src/app/api/diagrams/[id]/urls/route.ts` | GET presigned URLs for the scene | planned |
| `app/src/app/api/login/route.ts` | POST login | planned |
| `app/src/middleware.ts` | Session cookie check, redirects to `/login` | planned |

`src/lib/` will also hold the dynamo, s3 and session helpers once persistence and auth land.

## Endpoints owned

None yet. All six are planned.

| Method | Route | Purpose | Spec |
|---|---|---|---|
| GET | `/api/diagrams` | List diagrams, Scan on DynamoDB | none |
| POST | `/api/diagrams` | Create diagram id and name in DynamoDB | none |
| PATCH | `/api/diagrams/[id]` | Rename, or touch `updatedAt` after a scene PUT | none |
| DELETE | `/api/diagrams/[id]` | Delete in DynamoDB and S3 | none |
| GET | `/api/diagrams/[id]/urls` | Presigned GET and PUT URLs for the scene | none |
| POST | `/api/login` | Validate `APP_PASSWORD`, set signed session cookie | none |

Jobs, listeners or scheduled work: none.

## Locale and theme

The locale is resolved per request in `src/i18n/`, from the `NEXT_LOCALE` cookie and then `Accept-Language`, with `en` as the fallback.
There is no `[locale]` route segment, so the route table above is the whole of it.
The theme is `next-themes` with the class strategy, persisted in localStorage, and the editor receives both as props.

## Depends on

- `@excalidraw/excalidraw` npm package: the editor component, loaded client-side only.
- DynamoDB table (diagram index) and S3 scenes bucket: planned, not yet reached from code.

## Depended on by

- `deploy` (`.github/workflows/`): builds this module with OpenNext and updates the Lambda.
- `infra` (`infra/`): provisions the env vars this module reads.

## Configuration

None is read yet; the shell runs with no env file at all.
Planned: `APP_PASSWORD` and `SESSION_SECRET`, plus the table and bucket names passed by Terraform as Lambda env vars.
Locale and theme are never configured; both are read from the browser and persisted client-side.

## Testing

- Lint: `npm run lint` (ESLint, then Prettier in check mode).
- Typecheck: `npm run typecheck`.
- Unit: `npx vitest run`, over `tests/unit/`, Node environment, pure functions only.
- E2E: `npx playwright test --workers=1 --grep-invert @aws` locally and in `ci.yml`; specs tagged `@aws` run only in `e2e-dev.yml` against `napkin.dev.sdfles.com`.
- Playwright starts `npm run dev` itself unless `BASE_URL` is set.
- Install: `npm ci`. Build for AWS: `npx open-next build`.
