# styles

Every color in the changed lines is a shadcn semantic class built from the theme tokens (`bg-background`, `text-foreground`, `text-muted-foreground`, `border-border` and the rest the reference lists) or a `var(--token)` in CSS.
No hex, `rgb()`, `hsl()` or `oklch()` literal appears in a changed line outside `app/src/app/globals.css`.
No Tailwind palette class such as `text-red-500`, `bg-zinc-900` or `border-gray-200` appears in a changed line.
No arbitrary color value such as `bg-[#fff]` or `text-[rgb(0,0,0)]` appears in a changed line.
No `dark:` variant changes a color property; `dark:` on non-color properties is allowed.
Where the diff renders the Excalidraw component, it passes a `theme` prop derived from the app theme.
SVGs and icons in the diff use `currentColor`, not a fixed color.
Report as clean: token declarations under `:root` and `.dark` in `app/src/app/globals.css`, files under `app/src/components/ui/` as generated by the shadcn CLI, files under `app/tests/`, and `dark:` variants on spacing, borders width, opacity or layout.
